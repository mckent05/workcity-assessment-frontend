# Workcity Assessment Frontend
## Setup Instructions

## Prerequisites:

- A modern web browser
- Backend API running at http://localhost:3000


## Installation:
- git clone https://github.com/mckent/workcity-assessment-frontend.git
- cd workcity-assessment-frontend

## Backend repo:
- [Backend repo](https://github.com/mckent05/workcity-assessment-backend.git)


## Running the Application:
- To start the application run this code ```npm start`` on the root directory of the project

## Dependencies:

- React and ReactDOM (loaded via CDN)
- Axios (loaded via CDN)
- Tailwind CSS (loaded via CDN)



## Assumptions

- The backend API is running at http://localhost:3000.
- JWT token is stored in localStorage for authentication.
- Basic accessibility standards are followed (e.g., semantic HTML, keyboard navigation).
- Client-side routing is implemented using a simple custom router.
- No form elements are used for submissions.

## Pages

- Home: Welcome page with basic information.
- Login/Signup: Authentication pages for user login and registration.
- Client Dashboard: Lists all clients with links to view profiles.
- Add/Edit Client: Form to create or update client details.
- Project Dashboard: Lists all projects with client information.
- Add/Edit Project: Form to create or update project details.
- Client Profile View: Displays client details.

## Accessibility

- Semantic HTML used for better screen reader support.
- Keyboard navigation supported for all interactive elements.
- High-contrast colors used for better visibility.
